# AJ Beast Tech Lab

A hands-on technology lab built to develop practical skills in Linux, Bash scripting, system administration, and cybersecurity.

## Project: System Health Monitor

The System Health Monitor is a Bash script that performs automated health checks on a macOS system and provides a consolidated system status.

### Current Checks

- Disk Usage
- Memory availability
- System load
- Network connectivity 
- Overall system health
- Timestamped health-check logging

### Example Output

````text
=== AJ Beast System Health Check ===
Timestamp: 2026-08-18 17:30:00

Disk Status: OK
Memory Status: OK
Load Status: OK
Network Status: ONLINE

============================
OVERALL SYSTEM STATUS: HEALTHY
============================
